# 天气粒子系统

天气粒子系统作为独立示例模块维护，与图层目录分开组织。当前已建立目录入口和交互骨架，后续效果实现可逐项接入。

## 规划目录

- 降雨：雨线密度、风向、速度与强度
- 降雪：粒径、密度、飘移与距离衰减
- 雾：能见度、颜色与相机距离衰减
- 沙尘：颗粒、色调和风速
- 云层：云量、高度和流速
- 闪电：频率、亮度和触发区域

## 示例约定

每个天气示例后续应提供独立配置、初始化与销毁逻辑，并遵循图层实验室相同的运行约定：

```js
const effect = createWeatherEffect(viewer, options)

effect.start()

return () => effect.destroy()
```

返回清理函数可以确保切换示例时释放粒子、后处理阶段和事件监听器，避免多个天气效果叠加。

## 目录入口

从示例主页进入“天气粒子系统”，可以查看已经预留的效果分类。实际效果完成后，可将目录页替换为与图层模块一致的代码编辑器和 Cesium 实时预览。
